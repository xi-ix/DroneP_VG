`image + query -> Qwen prompt pool -> action pool -> C0 -> C1 -> final output`

## 样例信息

- 图像：`0000193_01705_d_0000112.jpg`
- Query：`A black-clad cyclist is crossing the intersection. There is a red tricycle at the top left.`
- 选中的动作：`person -> bicycle`
- 这条样例来自 `38+RL_loop/outputs/llm_dynamic/closed_loop_trace.json`

## Qwen 改写后的 prompt

Qwen 实际生成了 7 个短 prompt：

1. `A black-clad cyclist crossing an intersection`
2. `A cyclist in dark clothing moving through an intersection`
3. `A person in black attire crossing a road`
4. `A cyclist wearing dark clothing navigating an intersection`
5. `A cyclist in dark clothing traversing an intersection`
6. `A cyclist in dark clothing crossing a street`
7. `A cyclist in dark clothing crossing a road`

## action_pool

这里的 action_pool 分两层看：

- 原始 prompt pool: `STOP + 7 prompt texts`
- 经过 `source_prompt` 映射后的有效动作: `STOP, person, bicycle`

对应关系是：

- `bicycle` 相关 prompt：1, 2, 4, 5, 6, 7
- `person` 相关 prompt：3

## 中间输出

| Step | 内容 | 数量 |
| --- | --- | ---: |
| C0 | `query_alias_fallback` 初始候选 | 291 |
| C1 | 在 C0 上追加 `person` | 642 |
| Final | 再追加 `bicycle`，并做 Exp38 rescoring | 692 |
| Match | Exp38 重新对齐/重打分命中的候选 | 483 |

## 这一条流程怎么读

1. `image + query` 先送入 Qwen，得到一组更具体的短 prompt。
2. 这些 prompt 不直接作为最终输出，而是先映射到 `source_prompt`。
3. RL policy 在 `STOP / person / bicycle` 这类动作上选下一步。
4. 第一步从 `C0` 扩到 `C1`，第二步再扩到 `final`。
5. 最后经过 Exp38 的 rescoring，得到最终输出。
