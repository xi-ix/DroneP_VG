# 强化学习阶段模型结构说明（Qwen 动态动作版本）

## 1. 定位与边界

本阶段在论文概念图中位于 **GroundingDINO 初始候选输出之后、Exp38 最终排序/重评分之前**。Qwen 根据图像 query/caption 生成动态 prompt，策略网络从当前动态动作池中选择 STOP 或一个 prompt，调用 GroundingDINO 扩充候选集。

```text
GroundingDINO initial candidates C0
        ↓
Qwen query/caption → dynamic prompt pool
        ↓
Dynamic Policy Network
        ↓
STOP 或选择 prompt 扩展候选
        ↓
Merge + class-wise IoU dedup (0.92) → Ct+1
        ↺ 下一轮反馈
        ↓
RL output Cfinal → Exp38 sorter/rescoring（图外）
```

本文档对应 `38+RL_loop/llm_dynamic.py` 的最新实现，不是旧版固定 12 动作 `PolicyNet`。最新模型没有 Critic、Value Function、Advantage、固定 12 动作输出或固定 logits Action Mask。

实现口径说明：当前代码会在 RL 开始前调用一次 `exp38_rescore()` 初始化候选分数，并在 RL 结束后再次调用该函数。因此，“Exp38 位于 RL 之后”是论文框架图的模块化表达，指完整的最终排序/输出阶段位于 RL 之后；若严格按代码时序绘图，应在 RL 输入端额外标注 `initial Exp38 score initialization`。

## 2. 输入、动作与输出

### 2.1 输入

| 输入 | 形状/类型 | 说明 |
|---|---:|---|
| 当前候选池 `Ct` | `N×6` | `class_id, x1, y1, x2, y2, score` |
| 图像宽高 | 2 个整数 | 用于归一化候选框面积 |
| Query / Caption | 文本 | 输入 Qwen2.5-VL-3B-Instruct |
| Ground Truth | `M×5`，仅训练 | 计算候选扩展奖励 |

当 `t=0` 时，`Ct=C0`，其中 `C0` 是 GroundingDINO 初始候选池。

### 2.2 动态动作空间

```text
At = {STOP, prompt1, prompt2, ..., promptK}
```

`K` 随图像变化。Qwen 可能生成：`a white electric bicycle`、`a man wearing brown clothes`、`a group of people on the sidewalk`。每个 prompt action 保存 `text`、`class_id`、`llm_rank` 和 `llm_role`（primary/alias/attribute/relation/fallback）。STOP 保持当前候选池；非 STOP 动作调用对应 prompt 的 GroundingDINO 候选。

### 2.3 输出

对每个动作输出一个 score：

```text
scores = [zSTOP, z1, z2, ..., zK] ∈ R(K+1)
```

推理阶段在过滤已使用 prompt 后直接取最高 score；训练阶段在同一动态动作组内优化 softmax。RL 输出是扩展候选池 `Cfinal`，随后交给图外 Exp38 sorter/rescorer。

## 3. 38 维状态向量

`state_from_boxes(Ct, width, height)` 输出固定长度 `st∈R38`：

| 维度 | 特征组 | 说明 |
|---:|---|---|
| 1–6 | 全局统计 | 总候选数、平均分数、最高分、分数标准差、平均面积、小目标比例 |
| 7–16 | 类别数量 | 10 类候选数量，按 `count/80` 截断到 `[0,1]` |
| 17–26 | 类别最高分 | 10 类最高候选分数 |
| 27–36 | 类别平均面积 | 10 类归一化平均框面积 |
| 37 | 轮次比例 | `round_idx/2` |
| 38 | 剩余预算比例 | `(2-round_idx)/2` |

状态批量形状为 `[B,38]`。这些是统计量，不是 token embedding。

## 4. 20 维动作特征

每个动态动作转换为 `ai∈R20`：

| 维度 | 特征 |
|---:|---|
| 1 | STOP flag |
| 2–11 | 10 类 class one-hot |
| 12 | prompt length（截断归一化） |
| 13 | LLM rank（截断归一化） |
| 14 | prompt-query token overlap |
| 15 | round index |
| 16 | used-prompt flag |
| 17–20 | LLM role one-hot：primary/alias/attribute/relation |

STOP 使用同样的 20 维槽位，STOP flag 为 1，其余动作特征为 0。

## 5. Dynamic Policy Network

### 5.1 State Encoder

```text
st [B,38]
 → Linear(38,128) → LayerNorm(128) → ReLU
 → Linear(128,64) → ReLU
 → state embedding [B,64]
```

### 5.2 Action Encoder

```text
ai [B,20]
 → Linear(20,64) → LayerNorm(64) → ReLU
 → Linear(64,64) → ReLU
 → action embedding [B,64]
```

### 5.3 Fusion 与 Scorer

```text
h = concat(state_embedding, action_embedding,
           state_embedding ⊙ action_embedding) ∈ R192
h → Linear(192,96) → ReLU → Linear(96,1)
  → one score for the current state-action pair
```

对同一图像的 `K+1` 个动作分别前向，得到可变长度的 `K+1` 个 scores；不是固定长度 logits。

### 5.4 层数与参数量

| 模块 | Linear 层 | LayerNorm | 输出 |
|---|---:|---:|---|
| State Encoder | 2 | 1 | 64-D state embedding |
| Action Encoder | 2 | 1 | 64-D action embedding |
| Scorer | 2 | 0 | 1-D action score |
| 合计 | **6** | **2** | 可变数量 scores |

参数量为：State Encoder 13,504；Action Encoder 5,632；Scorer 18,625；总计 **37,761**。

```text
Lookup Embedding: 0
Learned state/action feature projections: 2
Attention: 0
Linear layers: 6
Trainable parameters: 37,761
```

这里的“2 个 feature projections”是 State/Action Encoder 的连续向量输出，不是 `nn.Embedding` 查表层。

## 6. 推理流程

```text
读取 Ct
→ Qwen 生成 dynamic prompt pool
→ 构造 At={STOP,prompt1,...,promptK}
→ 提取 st 和每个 ai
→ DynamicPolicyNet 输出 K+1 个 scores
→ 从动作池中移除已使用 prompt
→ 对剩余动作 scores 直接 argmax
```

若选择 STOP，则 `Ct+1=Ct`；否则调用选定 prompt 的 GroundingDINO，执行：

```text
Merge with Ct → class-wise IoU dedup (0.92) → Ct+1
```

`Ct+1` 回到下一轮状态提取，最多执行两轮反馈决策，最终输出 `Cfinal` 给 Exp38 sorter/rescorer。

## 7. 训练目标

训练按每个状态的动态动作组组织：`(state_t, action_i, reward_i)`。对每个动作执行候选扩展并与 GT 匹配，得到：

```text
r_i = 0.40 ΔRecall
    + 0.22 ΔRecall@0.75
    + 0.45 ΔSmallRecall
    + 0.15 ΔPrecision
    − box penalty − action cost − stop penalty
```

组内 soft target 和策略分布为：

```text
q = Softmax(reward / 0.04)
π = Softmax(action_scores)
```

代码中的损失是：

```text
L = −Σ q_i log π_i
    − 0.15 Σ π_i r_i
    − 0.005 H(π)
```

该损失同时更新 State Encoder、Action Encoder 和 Scorer；没有 Critic、Value Function 或 Advantage。

训练使用：`AdamW(lr=8e-4, weight_decay=1e-4)`，梯度裁剪最大范数为 `2.0`。

## 8. 与旧版固定动作模型的区别

| 项目 | 旧版 | 最新 Qwen 动态版本 |
|---|---|---|
| 动作数量 | 固定 12 | 每图 `K+1`，含 STOP |
| 动作来源 | 手工类别 prompt | Qwen query/caption prompt pool |
| 网络 | State-only Actor + Critic | State Encoder + Action Encoder + Scorer |
| 输出 | 12 logits | 每个 state-action 一个 score |
| Critic / Advantage | 有 | 无 |
| 训练 | policy/value/entropy | soft reward target + expected reward + entropy |
